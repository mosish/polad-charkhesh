# Brand identity

The owner confirmed the English name **Polad Charkhesh Arian Tak** and supplied PooladCharkhesh-clean.png on 2026-11-22. The Persian name remains پولاد چرخش آرین تک. The original 1254 × 1254 transparent PNG is preserved byte-for-byte at public-site/brand/logo.png. Responsive WebP derivatives, a versioned 48 px favicon, SVG fallback and social preview are derived from this file. Header, footer and administration use responsive assets; PDF exports use the PNG and its square aspect ratio.

Regenerate from an owner-approved PNG using `node scripts/build-brand-assets.mjs <source.png>` from the repository root, then review generated source and assets. No redesign or recoloring is applied to the logo.

A new one-time identity migration handles databases that already completed the former Tech migration. It corrects company names, displayed content/copy keys and generated product SEO, applies the new logo and updates the bundled social preview URL. Domains, identifiers, contact details and technical product data are retained. Later owner logo uploads remain supported.

The hero search submit action was also changed to a centered circular inset-glass button, replacing the square blue block, with a 44 px touch target in both themes.
